# Design Guidelines — Story of the City

> 이 문서는 모든 구현의 상위 헌장이다. 구현 전에 반드시 읽고 따른다.

## 고정 제약

| 항목 | 규칙 |
|------|------|
| 투영 | 2D 플랫 디오라마. 가로형 도시 파노라마, 5개 깊이 레이어 |
| 시점 | 건물은 정면/측면 실루엣이 분명한 2D 스프라이트 형태 |
| 논리 해상도 | 960×540 불변 |
| HiDPI | CSS 크기와 backing 해상도 분리, devicePixelRatio 반영 |
| 픽셀 스무딩 | 금지. `image-rendering: pixelated` 필수 |
| Canvas 레이아웃 | HUD 제외 전체 화면, 16:9 고정, letterbox/pillarbox |
| 불투명성 | 모든 요소 완전 불투명. rgba/globalAlpha 금지 |

## 레이어 시스템 (render.js LAYERS)

| Layer | World Y | Screen baseY | 역할 |
|-------|---------|-------------|------|
| 0 | 0–7 | 208 | 원경 스카이라인 실루엣 |
| 1 | 8–15 | 264 | 배경 건물군 |
| 2 | 16–23 | 326 | 중경 건물 |
| 3 | 24–31 | 382 | 근경 건물 |
| 4 | 32–41 | 416 | 전경 건물 (최대 스케일) |

## 애니메이션 규칙
- **Start 상태에서만** 모든 도시 애니메이션 진행
- **Pause 시 완전 정지** — 차량, 조명 깜빡임, 구름 등 예외 없음
- 구현: `if (state.running) animTick++;`

## 맵 생성 규칙
- 새로고침/재접속 시 **매번 새 시드**로 재생성
- `seed = Date.now() ^ (Math.random() * 0x7fffffff | 0)`
- 영구 맵 캐시/재사용 금지

## 도시 발전 단계

| Stage | 누적 타이머 | 주요 변화 |
|-------|-------------|-----------|
| 0 | 0–2h | 낮은 밀도, 기초 건물, 단순 아키타입 |
| 1 | 2–4h | 상업지구 확장, 중층 등장 |
| 2 | 4–6h | 고층 건물 증가, 교통 밀도 상승 |
| 3 | 6–8h | 랜드마크 등장, 야간 인프라 완성 |
| 4 | 8h+ | 최고 밀도, 모든 아키타입 활성 |

## 시간대별 조명

| tod | 광원 규칙 |
|-----|-----------|
| dawn | 청보라 앰비언트, 낮은 채도 |
| morning | 햇빛 우측, 긴 그림자 |
| day | 밝은 앰비언트, 선명한 그림자 |
| afternoon | 햇빛 좌측, 주황 틴트 |
| evening | 창문/가로등/네온 점등 시작 |
| night | 완전 야경, 차량 헤드라이트 활성 |

## 건물 디자인 원칙 (2D)
- 단순 박스 금지 — 지붕, 파사드, 창문, 층선, 간판, 옥상 구조물 필수
- 8개 아키타입 유지 — 각 아키타입은 2D 기준 고유 실루엣/디테일을 가짐
- 좌측 엣지 밝은 면 (sunlit), 우측 엣지 어두운 면 (shadow)으로 깊이 표현
- 층선은 1px 수평 어두운 선으로 표현

## 차량 디자인 원칙 (2D)
- 2D 사이드뷰 픽셀 아트 차량: body + cab + windshield + wheels + lights
- 도로 위에서 좌우로 이동
- 야간: 헤드라이트(앞) + 테일라이트(빨강, 뒤)

## 프레이밍 원칙
- 전체 가로 화면이 도시 풍경으로 꽉 차야 함
- 좌우 검은 여백, 빈 격자 공간 없음
- 5개 레이어가 sky → horizon → layers 0~4 → road → bottom 순서로 쌓임
- Stage 0도 이미 도시처럼 보여야 함
