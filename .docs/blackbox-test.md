# Blackbox Test — Story of the City

> 사용자 관점 테스트 케이스. 구현 내부를 몰라도 판단 가능한 기준으로 작성.

---

## BT-01 Start/Pause 애니메이션 제어
- **조건:** 페이지 로드 후 Start 클릭
- **기대:** 차량이 움직이고, 조명이 변하고, 애니메이션이 시작됨
- **조건:** Pause 클릭
- **기대:** 차량, 조명, 모든 움직임이 **즉시 완전 정지**. 단 하나의 요소도 움직이면 안 됨
- **조건:** 다시 Start 클릭
- **기대:** 정지된 상태에서 그대로 재개됨

## BT-02 새로고침 시 맵 재생성
- **조건:** F5 또는 브라우저 새로고침
- **기대:** 이전과 다른 도시 레이아웃이 생성됨 (건물 배치, 도로 구성 등)
- **금지:** 항상 동일한 맵이 나타남

## BT-03 Stage 전환 시각 변화
- **조건:** 타이머 누적 2시간 도달
- **기대:** 도시에 구조적 변화 발생 (건물 수 증가, 새 아키타입 등장 등)
- **조건:** 4h, 6h, 8h 동일 검증
- **기대:** 각 단계마다 이전 단계보다 밀도/복잡도가 명확히 증가함

## BT-04 고정 비율 반응형
- **조건:** 브라우저 창을 다양한 크기로 조절
- **기대:** Canvas가 항상 16:9 비율 유지, letterbox 또는 pillarbox로 여백 처리
- **금지:** Canvas가 가로/세로 독립적으로 늘어남

## BT-05 픽셀 스무딩 없음
- **조건:** 브라우저에서 Canvas를 확대해서 관찰
- **기대:** 픽셀이 선명하게 유지됨, 흐릿한 보간 없음

## BT-06 시간대별 조명 변화
- **조건:** 시스템 시각을 dawn/morning/day/afternoon/evening/night 구간으로 변경 후 실행
- **기대:** 각 시간대마다 하늘 색상, 건물 조명, 차량 라이트가 명확히 다름
- **특히:** evening~night에 창문/가로등 점등, 야간에 차량 헤드라이트 표시

## BT-07 빈 공간 없는 프레이밍
- **조건:** 어떤 창 크기/단계에서도 Canvas 내부 관찰
- **기대:** 화면 안에 빈 하늘이나 빈 땅이 보이지 않음
- **기대:** foreground, midground, background 모두 건물/인프라로 채워짐

## BT-08 차량 시각 품질
- **조건:** 주간 차량 관찰
- **기대:** 차체 실루엣으로 자동차임을 인식 가능 (블록/점이 아님)
- **조건:** 야간 차량 관찰
- **기대:** 헤드라이트/테일라이트 방향 구분 가능

## BT-09 HiDPI 품질
- **조건:** devicePixelRatio > 1인 고해상도 환경
- **기대:** 픽셀이 선명하게 렌더링됨, 저해상도처럼 뭉개지지 않음

## BT-10 장시간 실행 안정성
- **조건:** Start 상태로 30분 이상 방치
- **기대:** 프레임 드랍, 메모리 급증, 크래시 없음
- **기대:** 브라우저 콘솔에 에러 없음
