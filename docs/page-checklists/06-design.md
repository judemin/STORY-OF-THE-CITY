# Checklist 06 — 디자인 폴리시

## 완료 기준
도시 장면이 설계된 느낌을 주고, 모든 디자인 원칙을 준수한다.

## 체크리스트

- [ ] 8개 아키타입 각각 시각적으로 구분 가능
- [ ] 모든 건물에 지붕/측면/파사드/창문 표현
- [ ] 단순 박스 형태 없음
- [ ] 모든 요소 완전 불투명 (rgba/globalAlpha 없음)
- [ ] 그림자는 명시적 어두운 RGB 색상으로 표현
- [ ] 차량이 박스/점이 아닌 차 형태로 인식됨
- [ ] 도로/광장/공원이 의도적 공간으로 읽힘
- [ ] Stage 0 화면도 이미 도시처럼 보임
- [ ] Stage 4와 Stage 0 사이에 시각적 성장감이 명확함
- [ ] 카메라 프레임 안에 빈 땅/하늘 없음
