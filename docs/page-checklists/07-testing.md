# Checklist 07 — 테스트/검수

## 완료 기준
`.docs/blackbox-test.md`의 모든 케이스를 통과한다.

## 체크리스트

### 기능
- [ ] Start → 애니메이션 시작, Pause → 완전 정지
- [ ] 새로고침 → 다른 맵 생성됨
- [ ] 타이머 누적 2h/4h/6h/8h에 Stage 전환 발생

### 렌더링
- [ ] 다양한 창 크기에서 16:9 비율 유지
- [ ] HiDPI 환경(devicePixelRatio > 1)에서 선명한 픽셀
- [ ] 픽셀 스무딩 없음

### 시각 품질
- [ ] 모든 시간대(dawn~night) 조명 올바르게 변화
- [ ] 야간에 창문/가로등 점등 확인
- [ ] 차량이 차 형태로 인식됨
- [ ] 빈 카메라 공간 없음

### 안정성
- [ ] 30분 이상 실행 시 메모리/성능 이상 없음
- [ ] 콘솔 에러 없음
